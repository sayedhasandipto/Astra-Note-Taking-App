# 📝 Astra Note Taking App

A sleek, fast, and feature-rich Android application for taking and organizing notes effortlessly. Built with clean UI and offline storage support.

---

## ✨ Features
- 📌 **Create & Edit Notes:** Quickly jot down thoughts, ideas, and tasks.
- 🎨 **Clean UI:** Simple, modern, and user-friendly interface.
- ⚡ **Fast & Lightweight:** Optimized performance for smooth user experience.
- 📶 **Offline Mode:** Access and manage notes without needing an internet connection.
